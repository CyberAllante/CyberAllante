## What I build

**AI agents and workflows** that read inbound requests, pull out what matters, route them, update the systems of record, and escalate only what needs a person.

**Document intelligence** using vision models to turn plan sets, PDFs, and forms into structured data, cutting quote turnaround from days to same day.

**MCP servers** that expose internal tooling to AI agents so they can operate against live systems instead of only answering questions.

**Custom platforms** that replace rented software. ERPs, email sending platforms, texting platforms, client portals, and internal tools owned outright by the business instead of paid for per seat.

**Integrations** so a team's tools stop being islands. REST APIs, webhooks, OAuth, and custom connectors across CRM, inbox, calendar, billing, and project systems.
